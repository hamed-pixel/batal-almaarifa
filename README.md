# بطل المعرفة — دليل التشغيل

موقع ألعاب تعليمية للصفوف 1–12: القراءة، الذكاء وتمرين المخ، الرياضيات، تاريخ عُمان، العرب، ديننا الإسلامي.

- صفحة الطلاب: `https://موقعك/`
- لوحة المسؤول: `https://موقعك/#admin`

يعمل الموقع فورًا في **الوضع التجريبي** (البيانات في المتصفح فقط). لربطه بالإنترنت وتجميع نقاط كل الطلاب عندك اتبع الخطوات.

## 1) إنشاء مشروع Firebase (مجاني)
1. ادخل https://console.firebase.google.com ← **Add project** ← سمّه `batal-almaarifa`.
2. **Build > Authentication** ← Get started ← فعّل **Email/Password**.
3. **Build > Firestore Database** ← Create database ← اختر المنطقة (مثل `me-central2` أو `europe-west`) ← **Production mode**.
4. في Firestore افتح تبويب **Rules**، الصق محتوى ملف `firestore.rules` كاملًا ← **Publish**.

## 2) ربط الموقع
1. **Project settings** (الترس) ← **Your apps** ← أيقونة الويب `</>` ← سجّل التطبيق.
2. انسخ القيم من `firebaseConfig` والصقها في ملف `config.js`.

## 3) إنشاء حساب المسؤول
1. **Authentication > Users** ← **Add user** ← بريدك وكلمة مرور قوية.
2. انسخ **User UID** لهذا المستخدم.
3. **Firestore > Start collection** ← اسم المجموعة `admins` ← Document ID = الـ UID ← أضف حقلًا `role` = `admin` ← Save.

## 4) رفع الموقع على GitHub Pages
1. أنشئ مستودعًا جديدًا (مثلًا `batal-almaarifa`) وارفع كل الملفات.
2. **Settings > Pages** ← Branch: `main` ← Save.
3. في Firebase: **Authentication > Settings > Authorized domains** ← أضف `اسمك.github.io` ودومينك الخاص إن ربطته.

## 5) أول دخول كمسؤول
افتح `/#admin`، ادخل ببريدك، ثم من تبويب **الأسئلة** اضغط **رفع البنك الأولي** (156 سؤالًا). بعدها تقدر تعدّل وتضيف وتوقف أي سؤال.

## كيف يعمل
- الطالب يسجّل باسمه + رمز سري (6 خانات) ويختار صفّه وصورته.
- الأسئلة تُختار حسب الصف، وتتدرج في 5 مراحل لكل فئة حسب نقاطه (60، 150، 300، 500 نقطة)، مع رسالة تهنئة عند كل انتقال.
- الرياضيات وسلاسل الذكاء تتولّد تلقائيًا لكل صف فلا تتكرر.
- النقاط: 10 للإجابة الصحيحة + حتى 5 للسرعة + 2 عند سلسلة 3 إجابات صحيحة.
- المكافآت: 7 ألقاب تتصاعد مع النقاط، و20 شارة تظهر بنافذة احتفال مع مقولة تحفيزية.
- المسؤول يرى لكل طالب: النقاط، الجولات، الدقة، آخر دخول، عدد مرات الدخول، وسجلًا كاملًا بالأوقات، ويصدّر الكل إلى CSV.

## ملاحظات
- نسيان الرمز: احذف الطالب من لوحة المسؤول، ثم احذف حسابه من **Authentication > Users**، ليسجّل من جديد.
- الطالب الذي يفهم البرمجة يقدر نظريًا يغيّر نقاطه من المتصفح. لمسابقة بجوائز حقيقية نضيف تحقق النقاط على السيرفر (Cloud Functions).
- الخطة المجانية تكفي مئات الطلاب يوميًا.
